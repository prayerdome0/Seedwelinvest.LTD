# Seedwel Investment LTD

Static public website and a Firebase-backed portfolio administration workspace.

## Portfolio administration

- Open `admin.html` to manage published portfolio projects, protected image uploads, public portfolio details and share links.
- Open `projects.html` for the live, shareable portfolio.
- See [FIREBASE_SETUP.md](FIREBASE_SETUP.md) before using the admin in production. It explains Firebase Authentication, deploying the included Database/Storage Rules, migrating existing showcase cards and provisioning the 1 TB media-capacity target.

The repository deliberately contains no administrator password or private storage secret.
